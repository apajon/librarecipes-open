# Custom Fonts for LibraRecipes

This directory should contain the custom fonts specified in the design:

- **Merienda-Regular.ttf** - Logo font
- **Nunito-Regular.ttf** - UI font

For the demo, the app will fallback to system fonts if these files are not present.

To add custom fonts:
1. Download the font files
2. Place them in this directory
3. Update the font registration in main.py if needed
